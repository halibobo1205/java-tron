# Archive V3 Documents

Source paths written as `./...` in these reports are relative to the java-tron
repository root. `${ERIGON_ROOT}` denotes the reader's local Erigon checkout.
Historical reports retain their original commit references and technical conclusions;
local usernames and machine-specific checkout paths are not needed to reproduce them.

See [the harness guide](harness/README.md) for runnable private-chain tests. Generated
key tables, node configs, address caches and logs are local test artifacts, not
files to commit or publish. The harness generates fresh keys for each independent run.

Cleaning the current files does not remove previous versions from Git history.
